# Sistema de Gestión de Coworking

Trabajo de Habilitación - Arquitectura de Software

## Descripción

Documento de Especificación Arquitectónica (SAD) para una plataforma de gestión de coworking orientada a la administración de usuarios, membresías, reservas, control de acceso, facturación, pagos y notificaciones.

## Arquitectura seleccionada

La solución adopta una arquitectura basada en microservicios para separar las responsabilidades de usuarios, membresías, reservas, control de acceso, pagos, facturación y notificaciones.
